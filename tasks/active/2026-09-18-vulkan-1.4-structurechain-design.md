# Design Document : Initialisation Vulkan 1.4 via `vk::StructureChain` & Features Core

- **Date :** 2026-09-18
- **Auteurs :** @Antigravity & @dev (révisé et enrichi conjointement avec @bb3d-reviewer)
- **Statut :** REVISED (Revue d'architecture Vibe intégrée - Prêt pour implémentation TDD)
- **Fichier de tâche associé :** `tasks/active/TASK-VULKAN-1.4-INIT.md`

---

## 1. Contexte & Motivation

Actuellement, l'initialisation dans `VulkanContext.cpp` souffre de plusieurs limitations identifiées dans le Rapport d'Audit Vulkan (`docs/vulkan_audit/RAPPORT_AUDIT_VULKAN_MODERNE.md`) :
1. **API Version obsolète :** `appInfo` déclare `VK_API_VERSION_1_3`, alors que le SDK installé est `1.4.335.0` et que le GPU dédié (NVIDIA GeForce RTX 3070 Laptop) supporte nativement `apiVersion = 1.4.312` avec la conformité 1.4.1.3.
2. **Chaînage non sécurisé par pointeurs bruts :**
   ```cpp
   vk::PhysicalDeviceDynamicRenderingFeatures dynamicRenderingFeatures(VK_TRUE);
   vk::PhysicalDeviceSynchronization2Features sync2Features(VK_TRUE);
   dynamicRenderingFeatures.pNext = &sync2Features;
   // ...
   deviceCreateInfo.pNext = &dynamicRenderingFeatures;
   ```
   Ce chaînage manuel via des pointeurs locaux est propice aux pointeurs pendants (`dangling pointers`), non type-safe et difficile à étendre.
3. **Fonctionnalités modernes non activées au device :**
   - Vulkan 1.4 : `pushDescriptor`, `maintenance5`, `maintenance6`, `dynamicRenderingLocalRead`.
   - Vulkan 1.3 : `dynamicRendering`, `synchronization2`, `maintenance4`.
   - Vulkan 1.2 : `timelineSemaphore` (bloquant pour B11 / transferts asynchrones), `descriptorIndexing` (bloquant pour le bindless).
   - Vulkan 1.0/1.1 : `samplerAnisotropy` encore logé dans la structure plate `deviceFeatures` plutôt qu'intégré dans la chaîne moderne `PhysicalDeviceFeatures2`.

---

## 2. Objectifs Techniques & Décisions d'Architecture

1. **Instance & Application Info :** Déclarer `VK_API_VERSION_1_4` dans `vk::ApplicationInfo`.
2. **Négociation de Version :**
   - Calculer la version effective : `effectiveApiVersion = std::min(VK_API_VERSION_1_4, m_physicalDevice.getProperties().apiVersion)`.
   - `hasVulkan14 = (effectiveApiVersion >= VK_API_VERSION_1_4)`.
3. **Validation & Query Préalable des Features (Data-Driven) :**
   - **Règle absolue :** Ne JAMAIS activer un bit à l'aveugle sans avoir interrogé les capacités matérielles via `m_physicalDevice.getFeatures2(&queryChain)`.
   - **Politique Requise vs Optionnelle :**
     - *Requises (Hard Fail si absentes) :* `dynamicRendering`, `synchronization2`, `timelineSemaphore`, `samplerAnisotropy`.
     - *Optionnelles (Activées si supportées par le pilote) :* `pushDescriptor`, `dynamicRenderingLocalRead`, `maintenance5`, `maintenance6`, `descriptorIndexing`, `runtimeDescriptorArray`.
4. **Chaînage Type-Safe via `vk::StructureChain` :**
   - Utiliser `vk::StructureChain` pour Vulkan 1.4 :
     ```cpp
     using DeviceChain14 = vk::StructureChain<
         vk::DeviceCreateInfo,
         vk::PhysicalDeviceFeatures2,
         vk::PhysicalDeviceVulkan11Features,
         vk::PhysicalDeviceVulkan12Features,
         vk::PhysicalDeviceVulkan13Features,
         vk::PhysicalDeviceVulkan14Features
     >;
     ```
   - Utiliser `vk::StructureChain` concrète pour le fallback Vulkan 1.3 :
     ```cpp
     using DeviceChain13 = vk::StructureChain<
         vk::DeviceCreateInfo,
         vk::PhysicalDeviceFeatures2,
         vk::PhysicalDeviceVulkan11Features,
         vk::PhysicalDeviceVulkan12Features,
         vk::PhysicalDeviceVulkan13Features
     >;
     ```
5. **Gestion Épurée des Extensions de Device :**
   - Sur Vulkan 1.4 : seul `VK_KHR_SWAPCHAIN_EXTENSION_NAME` est requis. Toutes les promotions KHR (`synchronization2`, `dynamic_rendering`, `push_descriptor`, `maintenance4/5/6`) font partie intégrante du Core et ne doivent pas être redemandées comme extensions.
   - Sur Vulkan 1.3 : demander `VK_KHR_SWAPCHAIN_EXTENSION_NAME`.
6. **Décision sur `bufferDeviceAddress` :** Différé au Jalon 3 (GPU-driven culling & Mesh Shaders) afin de limiter le rayon d'impact et garder une matrice de test compacte.
7. **Alignement VMA :** Configurer `allocatorInfo.vulkanApiVersion = effectiveApiVersion`.
8. **Éco-système & Opacité :** Aucun type `vk::*` n'est divulgué dans les en-têtes clients (`Engine`, `Scene`, `Mesh`, `Component`). Les `waitIdle` historiques des transferts d'assets sont documentés comme dette technique adressée au Chantier 3 (Timeline Semaphores).

## 3. Implémentation Détaillée

### 3.1 Négociation & Query des Features

```cpp
uint32_t instanceVersion = VK_API_VERSION_1_4;
uint32_t deviceVersion = m_physicalDevice.getProperties().apiVersion;
uint32_t effectiveVersion = (deviceVersion >= VK_API_VERSION_1_4) ? VK_API_VERSION_1_4 : VK_API_VERSION_1_3;
bool isVulkan14 = (effectiveVersion >= VK_API_VERSION_1_4);
```

### 3.2 Requête des fonctionnalités (Query Chain)

```cpp
if (isVulkan14) {
    vk::StructureChain<
        vk::PhysicalDeviceFeatures2,
        vk::PhysicalDeviceVulkan11Features,
        vk::PhysicalDeviceVulkan12Features,
        vk::PhysicalDeviceVulkan13Features,
        vk::PhysicalDeviceVulkan14Features
    > queryChain;

    m_physicalDevice.getFeatures2(&queryChain.get<vk::PhysicalDeviceFeatures2>());

    const auto& supp10 = queryChain.get<vk::PhysicalDeviceFeatures2>().features;
    const auto& supp12 = queryChain.get<vk::PhysicalDeviceVulkan12Features>();
    const auto& supp13 = queryChain.get<vk::PhysicalDeviceVulkan13Features>();
    const auto& supp14 = queryChain.get<vk::PhysicalDeviceVulkan14Features>();

    // Vérification stricte des prérequis obligatoires
    if (!supp13.dynamicRendering || !supp13.synchronization2 || !supp12.timelineSemaphore) {
        throw std::runtime_error("VulkanContext: Required features (DynamicRendering, Sync2, TimelineSemaphore) not supported!");
    }

    // Construction de la chaîne de création
    vk::StructureChain<
        vk::DeviceCreateInfo,
        vk::PhysicalDeviceFeatures2,
        vk::PhysicalDeviceVulkan11Features,
        vk::PhysicalDeviceVulkan12Features,
        vk::PhysicalDeviceVulkan13Features,
        vk::PhysicalDeviceVulkan14Features
    > createChain;

    auto& dci = createChain.get<vk::DeviceCreateInfo>();
    dci.setQueueCreateInfos(queueCreateInfos);
    dci.setPEnabledExtensionNames(deviceExtensions);

    // Features 1.0 via PhysicalDeviceFeatures2
    auto& feat10 = createChain.get<vk::PhysicalDeviceFeatures2>().features;
    if (supp10.samplerAnisotropy) feat10.samplerAnisotropy = VK_TRUE;

    // Features 1.2
    auto& feat12 = createChain.get<vk::PhysicalDeviceVulkan12Features>();
    feat12.timelineSemaphore = VK_TRUE;
    if (supp12.descriptorIndexing) feat12.descriptorIndexing = VK_TRUE;
    if (supp12.runtimeDescriptorArray) feat12.runtimeDescriptorArray = VK_TRUE;
    if (supp12.descriptorBindingPartiallyBound) feat12.descriptorBindingPartiallyBound = VK_TRUE;
    if (supp12.descriptorBindingVariableDescriptorCount) feat12.descriptorBindingVariableDescriptorCount = VK_TRUE;

    // Features 1.3
    auto& feat13 = createChain.get<vk::PhysicalDeviceVulkan13Features>();
    feat13.dynamicRendering = VK_TRUE;
    feat13.synchronization2 = VK_TRUE;
    if (supp13.maintenance4) feat13.maintenance4 = VK_TRUE;

    // Features 1.4
    auto& feat14 = createChain.get<vk::PhysicalDeviceVulkan14Features>();
    if (supp14.pushDescriptor) feat14.pushDescriptor = VK_TRUE;
    if (supp14.dynamicRenderingLocalRead) feat14.dynamicRenderingLocalRead = VK_TRUE;
    if (supp14.maintenance5) feat14.maintenance5 = VK_TRUE;
    if (supp14.maintenance6) feat14.maintenance6 = VK_TRUE;

    m_device = m_physicalDevice.createDevice(createChain.get<vk::DeviceCreateInfo>());
} else {
    // Chemin Fallback Vulkan 1.3 concret
    vk::StructureChain<
        vk::PhysicalDeviceFeatures2,
        vk::PhysicalDeviceVulkan11Features,
        vk::PhysicalDeviceVulkan12Features,
        vk::PhysicalDeviceVulkan13Features
    > queryChain;

    m_physicalDevice.getFeatures2(&queryChain.get<vk::PhysicalDeviceFeatures2>());

    const auto& supp10 = queryChain.get<vk::PhysicalDeviceFeatures2>().features;
    const auto& supp12 = queryChain.get<vk::PhysicalDeviceVulkan12Features>();
    const auto& supp13 = queryChain.get<vk::PhysicalDeviceVulkan13Features>();

    if (!supp13.dynamicRendering || !supp13.synchronization2 || !supp12.timelineSemaphore) {
        throw std::runtime_error("VulkanContext: Required Vulkan 1.3 features not supported!");
    }

    vk::StructureChain<
        vk::DeviceCreateInfo,
        vk::PhysicalDeviceFeatures2,
        vk::PhysicalDeviceVulkan11Features,
        vk::PhysicalDeviceVulkan12Features,
        vk::PhysicalDeviceVulkan13Features
    > createChain;

    auto& dci = createChain.get<vk::DeviceCreateInfo>();
    dci.setQueueCreateInfos(queueCreateInfos);
    dci.setPEnabledExtensionNames(deviceExtensions);

    auto& feat10 = createChain.get<vk::PhysicalDeviceFeatures2>().features;
    if (supp10.samplerAnisotropy) feat10.samplerAnisotropy = VK_TRUE;

    auto& feat12 = createChain.get<vk::PhysicalDeviceVulkan12Features>();
    feat12.timelineSemaphore = VK_TRUE;
    if (supp12.descriptorIndexing) feat12.descriptorIndexing = VK_TRUE;
    if (supp12.runtimeDescriptorArray) feat12.runtimeDescriptorArray = VK_TRUE;

    auto& feat13 = createChain.get<vk::PhysicalDeviceVulkan13Features>();
    feat13.dynamicRendering = VK_TRUE;
    feat13.synchronization2 = VK_TRUE;

    m_device = m_physicalDevice.createDevice(createChain.get<vk::DeviceCreateInfo>());
}
```

### 3.3 Diagnostic & Visibilité dans VulkanContext

Ajouter des accesseurs de diagnostic propres sur `VulkanContext` :
```cpp
[[nodiscard]] uint32_t getApiVersion() const { return m_apiVersion; }
[[nodiscard]] bool isVulkan14Supported() const { return m_apiVersion >= VK_API_VERSION_1_4; }
[[nodiscard]] bool isFeatureEnabled(VulkanFeature feature) const; // ou snapshot de flags
```

## 4. Stratégie de Test & Validation

- **Test Unitaire `unit_test_02_vulkan_init` :**
  - Conserver le mode non-interactif / headless actuel.
  - Vérifier que `context.init(...)` réussit avec zéro warning de Validation Layer.
  - Vérifier par assertion que `context.getApiVersion() >= VK_API_VERSION_1_3`.
  - Vérifier que `synchronization2`, `dynamicRendering` et `timelineSemaphore` sont effectivement activés.
  - Logger explicitement les détails du GPU et des fonctionnalités activées.
- **CTest global :**
  - `ctest -R "unit_test_(00|02|03|08|09|12|13|21|25|26|27|shadows)"` doit rester à **100% PASS**.
